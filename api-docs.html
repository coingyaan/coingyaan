CoinGyaan API — Free Crypto Sentiment API for Developers

Version 1.0.0 · Launched March 2026 · Free to use

The CoinGyaan API gives developers free access to live crypto sentiment data — the same data powering coingyaan.com. No signup. No API key needed for the free tier. Just call the endpoint and get clean JSON back.

Free Requests
100/day
Cache Refresh
15 min
Uptime
24/7

Base URL

https://api.coingyaan.com

All endpoints return JSON. CORS is enabled — you can call this API directly from any browser or app. Free tier requires no API key.

Endpoints

GET /sentiment?coin=bitcoin Sentiment score for any coin

Returns the CoinGyaan sentiment verdict for any coin — BULLISH, BEARISH or NEUTRAL — based on three signals: price momentum, Fear and Greed Index and RSI(14). BTC and ETH are served from cache. Other coins are fetched live.

Parameters
coin (string, required) — coin name or symbol e.g. bitcoin, ethereum, solana, btc, eth
Example Request
GET https://api.coingyaan.com/sentiment?coin=bitcoin
Example Response
{ "coin": "bitcoin", "symbol": "BTC", "price": 71542, "change24h": 1.28, "sentiment": "neutral", "rsi": 49, "feargreed": { "value": 15, "label": "Extreme Fear" }, "signals": { "price": "neutral", "feargreed": "bearish", "rsi": "neutral" }, "updatedAt": "2026-03-15T16:16:36.200Z" }
GET /prices Live prices for top 5 coins

Returns live USD prices and 24h change for Bitcoin, Ethereum, Solana, BNB and XRP. Refreshed every 15 minutes.

Example Request
GET https://api.coingyaan.com/prices
Example Response
{ "data": { "bitcoin": { "usd": 71542, "change24h": 1.28, "marketCap": 1431798349509 }, "ethereum": { "usd": 2097, "change24h": 1.11, "marketCap": 253175467872 }, "solana": { "usd": 87.99, "change24h": 1.41 }, "bnb": { "usd": 660, "change24h": 1.13 }, "xrp": { "usd": 1.42, "change24h": 1.97 } }, "updatedAt": "2026-03-15T16:16:36.200Z" }
GET /feargreed Crypto Fear and Greed Index

Returns the current Crypto Fear and Greed Index value and label. Score ranges from 0 (Extreme Fear) to 100 (Extreme Greed).

Example Request
GET https://api.coingyaan.com/feargreed
Example Response
{ "data": { "value": 15, "label": "Extreme Fear" }, "updatedAt": "2026-03-15T16:16:36.200Z" }
GET /trending Top 5 trending coins right now

Returns the top 5 trending coins on CoinGecko right now with live price and 24h change.

Example Request
GET https://api.coingyaan.com/trending
Example Response
{ "data": [ { "id": "bittensor", "name": "Bittensor", "symbol": "TAO", "price": 275.68, "change24h": 17.82 }, { "id": "bitcoin", "name": "Bitcoin", "symbol": "BTC", "price": 71490, "change24h": 1.34 }, { "id": "solana", "name": "Solana", "symbol": "SOL", "price": 87.91, "change24h": 1.35 } ], "updatedAt": "2026-03-15T16:16:36.200Z" }
GET /altseason Altcoin Season Index

Returns the CoinGyaan Altcoin Season Index score and phase. Score is based on how many of the top 50 altcoins are outperforming Bitcoin.

Example Request
GET https://api.coingyaan.com/altseason
Example Response
{ "data": { "score": 33, "phase": "mixed", "outperforming": 16, "totalAlts": 49, "avgAltChange24h": 0.89, "btcChange24h": 1.29 }, "updatedAt": "2026-03-15T16:16:36.200Z" }

Code Examples

JavaScript / Fetch

fetch('https://api.coingyaan.com/sentiment?coin=bitcoin') .then(res => res.json()) .then(data => { console.log(data.sentiment); // "bullish" | "bearish" | "neutral" console.log(data.price); // 71542 console.log(data.rsi); // 49 });

Python

import requests res = requests.get('https://api.coingyaan.com/sentiment?coin=ethereum') data = res.json() print(data['sentiment']) # bullish | bearish | neutral print(data['price']) # current price

Node.js

const res = await fetch('https://api.coingyaan.com/feargreed'); const data = await res.json(); console.log(data.data.value); // 15 console.log(data.data.label); // "Extreme Fear"

Rate Limits

The free tier allows 100 requests per day per IP address. If you exceed this limit you will receive a 429 response. Cache is refreshed every 15 minutes so there is no need to call more frequently than that for price and sentiment data.

// 429 Rate limit response { "error": "Rate limit exceeded. Free tier allows 100 requests per day. Upgrade to Pro at coingyaan.com" }

Error Responses

Code Meaning
200 Success
404 Coin not found
429 Rate limit exceeded
503 Cache warming up — try again in 30 seconds
500 Internal server error
