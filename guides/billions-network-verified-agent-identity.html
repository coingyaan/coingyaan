How to Create a Verified AI Agent Identity on Billions Network

5 min read · CoinGyaan Team · March 2026

🎁 Instant Reward: Complete this tutorial and link your verified AI agent to earn +2000 Power Points on Billions Network!

Billions Network lets you create verified AI agent identities that are linked to your human profile. This guide shows you exactly how to set up your agent's DID passport step by step and claim your +2000 Power Points reward.

Before You Start

Make sure you have these ready:

  • A verified Billions Network account (sign up here)
  • Node.js installed on your PC (download here)

If you are on Android you will need Termux app. Install it then run this command first:

pkg install nodejs

Step 1: Open Terminal

Windows: Press Win + X then click PowerShell

Mac: Open Terminal from Applications

Android: Open Termux app

Step 2: Install the Tool

Copy and paste this command into your terminal:

npx clawhub@latest install verified-agent-identity

Wait for it to finish installing. This might take 1 to 2 minutes.

Step 3: Navigate to Scripts Folder

Run this command to move into the scripts folder:

cd skills/verified-agent-identity/scripts

Then install the required dependencies:

npm install

Step 4: Create Your Agent's Ethereum Identity

This creates your agent's blockchain wallet:

node createNewEthereumIdentity.js

⚠️ Important: This generates your agent's private key and public key and wallet address. Save these somewhere safe. Never share your private key with anyone.

Step 5: Generate Verification Link (Windows)

If you are on Windows follow these steps. Mac and Linux users can skip to the next section.

First open the script file in Notepad:

notepad manualLinkHumanToAgent.js

Press Ctrl+A to select all the text then delete it. Now copy this entire code block and paste it into Notepad:

const { createPairing } = require("./linkHumanToAgent");
const { formatError } = require("./shared/utils");

async function main() {
  try {
    const args = { challenge: '{"name":"My Agent","description":"My personal AI agent"}' };
    const challenge = JSON.parse(args.challenge);
    const url = await createPairing(challenge, args.did);
    console.log(url);
  } catch (error) {
    console.error(formatError(error));
    process.exit(1);
  }
}

main();

Press Ctrl+S to save then close Notepad.

Mac and Linux users: You can skip the Notepad steps above. Instead just run this command directly in your terminal:

node manualLinkHumanToAgent.js --challenge '{"name":"My Agent","description":"My personal AI agent"}'

Step 6: Run the Script

Now run the modified script:

node manualLinkHumanToAgent.js

You will see a link appear in your terminal that looks like this:

https://wallet.billions.network#request_uri=https://identity-dashboard.billions.network/shortener/xxxxx

Step 7: Sign and Complete

Almost done! Follow these final steps:

  1. Copy the entire link from your terminal
  2. Open it in your browser
  3. Login with your wallet or Gmail linked to your Billions account
  4. Click the Sign button to verify

🎉 Congratulations! Your AI agent now has its own verified DID passport linked to your Billions human profile.

💰 You have earned +2000 Power Points! Check your Billions Network account to see your reward.

What You Can Do Next

Now that your agent has a verified identity and you have earned your +2000 Power Points you can use it to interact with other AI agents on Billions Network and participate in the decentralized AI economy and build autonomous applications.

What Are Power Points?

Power Points are Billions Network's reward system for early adopters and active participants. By creating a verified AI agent you automatically receive +2000 Power Points credited to your account.

These points may be used for future rewards and airdrops and ecosystem benefits on Billions Network. The more you participate the more Power Points you can earn.
