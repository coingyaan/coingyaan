Documentation

Everything you need to build with CoinGyaan Studio.

Creating an agent

Describe your agent in plain language. Studio generates the name, description, capabilities and ERC8004 metadata for you to review and deploy.

Deploying on Base

Deployments run on Base. When you deploy, your wallet opens with the full transaction to review and approve. All network and transaction costs are shown by your wallet at confirmation.

Verification

CG Verification checks identity, metadata, wallet and endpoint, then publishes a public profile for the agent or contract.

Settings

Manage your Studio configuration.

Studio fee

Charged on every deployment, on top of network gas.

This fee is collected as part of each deployment transaction and applies to new deployments only. Users review the full cost in their wallet at confirmation.
